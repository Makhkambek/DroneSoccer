## 🔧 Как обновить страницу для использования переводов

### Пример (для любой страницы):

```tsx
'use client';

import { useTranslations, useLocale } from 'next-intl';
import Link from 'next/link';

export default function MyPage() {
  // Используйте нужный namespace из JSON файлов
  const t = useTranslations('lessons'); // или 'apply', 'competitions' и т.д.
  const locale = useLocale();

  return (
    <div className="pt-48">
      {/* Замените хардкод на переводы */}
      <h1>{t('hero.title')}</h1>
      <p>{t('hero.subtitle')}</p>

      {/* Добавьте locale ко всем ссылкам */}
      <Link href={`/${locale}/path`}>Link Text</Link>
    </div>
  );
}
```

### Шаги:
1. Добавьте `'use client';` вверху файла
2. Импортируйте хуки: `import { useTranslations, useLocale } from 'next-intl';`
3. Используйте хуки в компоненте
4. Замените весь текст на `t('key')`
5. Обновите все `<Link href="/path">` на `<Link href={`/${locale}/path`}>`

## 🐛 Решение проблем

### Переводы не отображаются
- Убедитесь, что ключ существует в обоих JSON файлах
- Проверьте правильность namespace в `useTranslations()`

### 404 ошибки
- Все ссылки должны включать `/${locale}/`
- Проверьте, что страница находится в `/app/[locale]/`

### Язык не переключается
- Очистите кеш браузера
- Перезапустите dev сервер: `npm run dev`
